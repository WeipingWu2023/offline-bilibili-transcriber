# 常见问题

**必须电脑或USB调试吗？** 不需要。手机下载Releases中的APK和模型ZIP，安装并导入即可。Android10以下不支持。

**ZIP要解压吗？** 不要；直接用应用“模型→导入模型ZIP”。系统文件选择器中看不到文件时，切换到Downloads或文件管理器。不要选GitHub自动生成的Source code。

**安装失败？** 检查Android版本、存储和APK是否完整，按系统提示允许当前安装来源。若提示“与现有包冲突”或签名不匹配，可能已有源码debug版或他人签名版。不要直接卸载重要数据：先导出文稿和需要的音频。正式发行版与原开发测试版签名不同，无法直接覆盖；后续同一发行签名的更新可保留数据。

**升级会保留数据吗？** 同一发行签名的APK使用覆盖安装，通常保留私有数据；仍建议先导出重要文稿。卸载、清除数据会删除录音、文稿和模型。仓库自编版本签名不同，不能混用升级。

**为什么要求录音/麦克风权限？** Android播放捕获需要RECORD_AUDIO，系统可能显示“麦克风”。代码使用AudioPlaybackCaptureConfiguration，没有麦克风AudioSource。

**录音没有声音？** 看源应用是否真正播放、有声路由及系统授权范围；先录允许捕获的对照音并回听。暂停、静音、源应用策略、受保护内容、独立播放UID或厂商系统都可能影响捕获。不能只凭静音确定原因；不自动转为麦克风，也不绕过限制。改用自己有权使用的本地文件。

**能录直播或会员视频吗？** 未验证，不保证。是否允许由Android、播放器和音轨策略决定，不由本应用强制开启。

**切换到Bilibili怎么停止？** 用通知的停止按钮，或返回应用停止。Android13+拒绝通知权限可能看不到常规停止通知，此时返回页面操作。

**转写慢/发热/内存不足？** 本地CPU模型以准确度优先，速度因手机而异。先用短音频验证，保持足够空间；高温保护可能暂停，待冷却再恢复。低内存系统可能终止进程，再打开文稿手动恢复。没有承诺后台无限执行。

**原文和标点版不同？** 标点版只允许保守的标点变化和分段；词句或数字发生变化会回退原文。标点也可能有错。需要润色时创建并保存独立编辑稿。

**支持粤语/Qwen3吗？** SenseVoice有粤语配置，其他受支持ONNX模型有导入接口；默认只提供SenseVoice包，仅普通话短样本经过本机验证。不能直接导入PyTorch权重。

**能离线吗？** APK没有INTERNET权限。模型下载/导入后本地识别不需网络。手机浏览器、网盘导出或系统剪贴板由其他组件管理。

**图片是实际应用截图吗？** 首页海报是AI生成的推广插画，其中音频和文稿卡片为概念示意。实际界面是录音、文稿、模型三个页面。
