# 小棋听记使用说明

公开发行版使用正式签名；原开发测试版签名不同，不能直接覆盖。后续同一发行签名可覆盖更新。安装前参考README及FAQ。没有 INTERNET 权限，没有云识别或后端。APK 包含 sherpa-onnx 运行库，识别模型以独立 ZIP 导入一次，之后重复离线使用。

## 首次准备

1. 安装 `xiaoqi-tingji-v1.0.1.apk`（GitHub Releases中的已签名版本）。
2. 将 `sensevoice-offline-models.zip` 放到手机 Downloads 或本地文件夹。
3. 打开“小棋听记”→“模型”→“导入模型 ZIP”，在系统文件选择器中选中 ZIP。保持页面直至完成。导入会校验每个文件的 SHA256、限制大小并防止 ZIP 路径穿越。
4. 导入后模型保存在应用私有目录。可以断网使用。模型 ZIP 是一次性安装材料，确认导入成功后可自行删除 Downloads 中的副本。

## 录制和转写

- “录音”页选择官方 Bilibili 包名，授权并开始；切换到 Bilibili 播放有权录制的内容，再从通知或页面停止。每次录音重新确认系统投影授权。不使用麦克风、不创建画面录制。
- 停止录音后去“文稿”，选择录音、模型与语言，点“开始离线转写”。不在录制过程中生成实时字幕。
- 也可以在“录音”页导入有权使用的本地音频 / 视频。通过 Android 原生解码器读取音轨，不读取 Bilibili 私有缓存、不解密 DRM。
- 转写服务在后台继续，通知和“文稿”页显示进度。解码阶段显示已处理秒数，识别阶段显示百分比。
- “暂停”会等待当前 native 识别调用完成，随后保存状态。恢复重用已经完整生成的 16 kHz 解码副本，重新扫描 VAD，但跳过已识别并持久化的段落。解码中暂停时，尚未完成的解码副本丢弃，恢复需重新解码。
- 如果进程被系统终止，下次打开会把未完成任务标为中断，可以手动恢复。不会自动复用投影授权或自动重开录音。
- 重做转写或换模型会创建新的识别记录；旧结果、参考稿和编辑稿保留，可以切换比较。

## 三种文本

1. **原文**：未经修改的模型识别文本与语音段时间范围。它不等于人工保证正确的逐字稿，可能有漏词、错词或模型幻觉。空识别段显式提示回听，不补写。
2. **标点版**：CT-Transformer 添加标点，再根据语音间隔和长度分段。不进行 LLM 润色或事实改写。若模型改变词句或数字表示，会拒绝该段标点结果、保留原文；标点仍可能不正确，需要核对。
3. **编辑稿**：从标点版创建，手工编辑并单独保存，不覆盖识别原文。切换记录前请点“保存编辑稿”。

TXT / Markdown 导出通过系统文件保存器执行。原文导出包含段落时间范围；其他模式保留对应文本、模型与任务元数据。Markdown 文件使用 `.md` 后缀。复制文本使用 Android 系统剪贴板；系统剪贴板及用户指定的导出提供方由用户管理，应用没有后台上传功能。

## 历史、搜索和删除

“文稿”页支持修改标题、搜索标题 / 识别原文 / 标点版 / 已保存编辑稿。每个音频可有多个模型的识别记录。

删除单条记录会删除原音频、标准化副本、所有关联识别段、参考稿和编辑稿。“录音”页也可删除所有测试音频和文本，保留模型。导出的副本及手机 Downloads 中的一次性模型 ZIP 需自行删除。

## 准确度评估

1. 用短而有代表性的有权使用的讲话音频创建任务。
2. 听音频并人工纠正，获得纯文字参考稿；不要含时间戳，不要用另一个 ASR 输出充当真值。
3. 打开对应任务的“准确度评估”，粘贴参考稿，记录漏词、疑似幻觉和专名错误的人工标注。
4. 点击“计算 CER 并保存评估”，可导出报告。
5. 对同一音频选择另一模型创建新任务，使用同一参考稿和标注标准比较。

CER = (替换 + 删除 + 插入) / 参考字符数。评估忽略 Unicode 标点和空白，保留汉字、字母、数字和大小写，使用 Unicode code point；上限 10000 字，较长内容按片段评估。插入 / 删除字符只是编辑距离指标，不能自动等同于幻觉 / 语音遗漏，需人工判断。相同代价的对齐采用对角优先、删除次之、插入最后，便于复现计数。没有人工参考稿就不宣称准确率。

## 模型包格式与替代模型

ZIP 根部为 `manifest.json`，`schema=1`、`name`、`engine`（sensevoice / paraformer / qwen3）及 `sha256`（所有其他文件的相对路径与 SHA256）。不接受不完整校验清单。模型内容仍须来自可信发布方；校验清单本身不是发布方数字签名。

```text
manifest.json
asr/model.int8.onnx          SenseVoice / Paraformer
asr/tokens.txt
punct/model.int8.onnx        CT-Transformer 中英 INT8
vad/silero_vad.onnx
licenses/...                模型来源的许可和说明
```

Qwen3-ASR 包改为 `asr/conv_frontend.int8.onnx`、`asr/encoder.int8.onnx`、`asr/decoder.int8.onnx` 和 `asr/tokenizer/` 的完整官方 tokenizer 文件，仍需 VAD / 标点模型及完整校验清单。只有经过 sherpa-onnx 支持的 ONNX 转换才能使用，不能把原始 PyTorch 权重直接导入。该引擎入口已接入官方 API，Qwen3 具体包和本机效果未经验证，默认包只含 SenseVoice。

默认 SenseVoice Small INT8（2024-07-17）支持普通话、粤语和自动语言。可按同样格式导入粤语微调版 SenseVoice 或另一个受支持的 Paraformer 模型进行比较。非 SenseVoice 引擎使用模型自身语言配置，不假装支持强制粤语参数。

## 已知边界

- 平台：Android 10+，compile/targetSdk 35；Android 14 的内部捕获已实测。Android 15+ 转写使用 mediaProcessing 类型；Android 10–14 使用 dataSync 类型。每次转写从可见页面由用户启动，不从开机或后台自动发起新录音。
- 转写使用 CPU，ASR 两线程、VAD 和标点各一线程，逐段串行处理，避免整段音频全部载入内存。模型加载仍占数百 MiB；不同模型可能更高。
- 设备严重发热时等待降温，持续过热 5 分钟转为暂停。系统前台服务超时或用户暂停会保存已完成段落；单次转写执行上限 3 小时，可手动恢复。
- VAD 阈值 0.35，最短语音 0.1 秒，停顿 0.5 秒，最长语音段 20 秒。很轻的声音、音乐中讲话、重叠说话或分段边界仍可能漏词，需回听；不承诺所有弱语音完整保留。
- 时间戳为解码音频内的语音段范围，并保留模型返回的 token 时间（如有）。不等于视频平台时间轴、说话人分离或逐字人工对齐。
- WAV 原生处理 PCM16 / float32、1–8 声道、8–192 kHz；其他容器使用设备自带 MediaCodec。格式不支持、加密音轨或时间戳严重异常会失败并报告，不绕过保护。
- 单次录制上限 6 小时，导入源文件上限 1 GiB，解码上限 24 小时；这些是代码限制，不代表已实测的录音时长。标准化副本占约 1.92 MB/分钟，另外保留原始音频，需足够本地空间。
- 没有自动补词、专名纠错或 LLM 改写。编辑稿完全由用户控制。用户明确暂缓的直播、会员内容、长录音、完整重复捕获验收没有执行。
